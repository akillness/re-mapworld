# 시스템 권한 관리 및 차단 방지 전략

## 1. 파일 시스템 권한 (File Permissions)
- **조치**: 작업 디렉토리() 및 하위 모든 파일에 대해 **777 권한(Full Access)**을 부여하여 프로세스 간 데이터 교환 시 발생할 수 있는 Permission Denied 오류를 원천 차단함.
- **적용**: `chmod -R 777` 명령 상시 유지.

## 2. 프로세스 실행 권한 (Process Privileges)
- **전략**: `mapleworld` 프로세스 분석 및 로그 추출 시 시스템 차단이 발생하지 않도록, 모든 모니터링 스크립트를 사용자 레벨 최대 권한으로 실행.
- **방어**: 백그라운드 프로세스() 실행 시 표준 에러를 로그로 리다이렉션하여 차단 징후 즉시 포착.

## 3. 지속적 권한 유지
- 크론 잡 실행 시마다 권한 상태를 체크하고 필요시 재설정하는 루틴을 포함하여, 자동화 작업 중 권한 상실로 인한 중단 방지.
