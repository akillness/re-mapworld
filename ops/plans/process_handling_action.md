# 🕹️ 프로세스 핸들링 및 기획 기반 동작 계획

## 1. 프로세스 장악 (Process Handling)
- **타겟**: `mapleworld.exe` (에디터/클라이언트)
- **핸들링**: 
    - 프로세스 생존 신호(Heartbeat)를 5초 주기로 확인.
    - 엔진 창이 비활성 상태일 경우, 시각 분석을 통해 포커스 복구를 시도하거나 제오임당님께 수동 조작 요청.

## 2. 모니터링 기반 동작 계획 (Action Plan)
- **분석 데이터**: 캡처된 에디터 화면의 스크립트 리스트.
- **동작**:
    - **Step 1**: `SurvivalManager` 컴포넌트가 존재하지 않을 경우, 'New Script' API 강제 호출.
    - **Step 2**: 기획 문서(`expanded_spec_v2.md`)의 위험도 1% 로직을 스크립트 바디에 주입.
    - **Step 3**: '적용' 버튼 클릭 화면 포착 후 검증 단계로 전환.

## 3. 기획 준수 (Spec Alignment)
- **위험도**: 10초당 1% (수치 오차 정밀 모니터링).
- **HUD**: 상단 중앙 게이지 배치 (시각적 앵커 포인트 조정).
- **탈출**: 보스 처치 후 30초 카운트다운 타이머 동작 확인.
