# 🔥 MSW 엔진 코드 주입 및 동작 검증 (빡센 모드)

## 1. 엔진 프로세스 장악 (Process Control)
- **대상**: 현재 실행 중인 MapleStory Worlds 에디터.
- **감시**: 에디터의 스크립트 에디터 윈도우 활성화를 0.1초 단위로 추적.

## 2. gjc 강제 주입 시나리오
- **Step 1**: 에디터 내 '새 스크립트 컴포넌트' 생성 버튼 좌표 인식.
- **Step 2**: `SurvivalManager.lua` 내용을 클립보드 방식으로 엔진 내부 에디터에 강제 타이핑/주입.
- **Step 3**: '적용(Apply)' 또는 '저장(Save)' 단축키 트리거링.

## 3. 실시간 동작 로그 추출
- 엔진 내부의 `log()` 함수가 출력하는 데이터를 `logs/engine_trace.log`로 파이핑하여 기획 수치(10초당 1%)와 대조.

## 4. 즉각 보고 루틴
- 주입 성공 시: 즉시 보고.
- Gap 발견 시: 즉시 수정 및 재주입.
