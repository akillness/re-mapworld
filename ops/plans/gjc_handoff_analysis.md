# gjc Handoff: 엔진 화면 분석 및 기능 검증 가이드

## 1. 이미지 분석 기반 피드백 (Image Analysis)
- **UI 오버레이 확인**: 실제 엔진에서 렌더링된 위험도 게이지의 위치와 가독성 체크.
- **맵 레이아웃 매핑**: 세이프 존의 시각적 경계와 스크립트상의  판정 영역 일치 여부 확인.
- **보스 스폰 시각화**: 보스 등장 시 이펙트와 충돌 박스 동작 확인.

## 2. gjc 공유 및 전달 (Handoff to Guide)
- 분석된 시각적 데이터를 의 파라미터로 환산하여 에게 전달.
- 예: "이미지상 세이프 존이 협소함 ->  1.5배 상향 조정 필요."

## 3. 동작 검증 (Verification)
- 세션 3회 연속 실행 시 데이터 누락 여부 체크.
- 보스 처치 후 포탈 생성까지의 지연 시간(Latency) 측정 및 최적화.
