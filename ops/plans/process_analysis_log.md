# MapleStory Worlds 프로세스 분석 및 개발 로그

## 1. 프로세스 탐지 (Process Detection)
- **탐지 대상**:  클라이언트,  엔진 프로세스.
- **상태**: 현재 제오임당님의 로컬 환경에서 엔진 툴이 활성화되어 있음을 확인.

## 2. 화면 관찰 로그 (Vision Log)
- **HUD 분석**: 위험도 게이지가 엔진의 기본 UI 레이어 위에서 어떻게 렌더링되는지 관찰.
- **좌표 동기화**: 엔진 툴 상의 캐릭터 X, Y 좌표를 추적하여 세이프 존()의 판정 로직과 대조.
- **로그 매핑**: 엔진의 디버그 콘솔 출력물을 와 통합하여 '동작 증거'로 활용.

## 3. 개발 로그 반영 (Evolution)
- 프로세스 화면 분석을 통해 발견된 **UI 겹침**, **프레임 드랍**, **물리 판정 오류** 등을 즉시 에게 전달하여 코드를 보정.
- 동작 검증 완료 시마다  태그를 붙여 개발 로그에 기록.
