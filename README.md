# MapleSurvivalExpedition

MapleSurvivalExpedition is a MapleStory Worlds survival-expedition prototype. The player manages health and hunger while clearing escalating monster waves. The repository is intentionally structured so an agent can validate and simulate the gameplay loop before the scripts are pasted into MSW Maker.

## Implemented gameplay

- Player survival stats: health, hunger drain, starvation damage, eating, healing, experience, score, level-up reset.
- Wave director: five target waves, wave/rest phases, risk percentage, completion state.
- Monster spawning: wave-scaled spawn cap and interval, real `_SpawnService:SpawnByModelId` support, safe simulated spawn mode when `MonsterModelId` is not configured yet.
- Monster component: health, attack ticks, damage, defeat cleanup.
- HUD bridge: synchronized text fields for stage, health, hunger, risk, and victory visibility.
- Agent-native harness: validation, deterministic simulation, MSW Maker launch check, MakerMCP status probe.

## Local validation and execution commands

```bash
python tools/msw_project_cli.py validate
python tools/msw_project_cli.py simulate --seconds 420
python tools/msw_project_cli.py maker-status
python tools/msw_project_cli.py launch-engine
python tools/msw_project_cli.py write-run-report
```

The simulation is deterministic and currently verifies that the five-wave expedition can complete without player death.

## Applying to MapleStory Worlds Maker

1. Start MSW Maker: `D:\MapleStory Worlds\msw.exe`.
2. Create or open a world.
3. In Workspace, create scripts matching these filenames:
   - `PlayerSurvivalStats`
   - `MonsterSpawner`
   - `MonsterAgent`
   - `SurvivalGameManager`
   - `SurvivalHudBridge`
4. Paste each corresponding `.lua` file into the MSW script editor.
5. Attach components:
   - Attach `PlayerSurvivalStats` to the default player model.
   - Attach `MonsterSpawner` to one or more empty spawn-point entities.
   - Attach `MonsterAgent` to the monster prefab/model.
   - Add `SurvivalGameManager` as a global logic script.
   - Attach `SurvivalHudBridge` to a UI manager entity if HUD text is available.
6. Configure `MonsterSpawner.MonsterModelId` with the monster model Entry ID copied from Resource Storage. Leave it empty for log-only simulated spawns.
7. Press Play and check the Console for `[MapleSurvivalExpedition]` logs.
