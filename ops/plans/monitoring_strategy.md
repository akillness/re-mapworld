# 엔진 툴 동작 추적 및 모니터링 전략

## 1. 정적 분석 (Static Analysis)
-  폴더 내의 MSW 원본 스크립트와 현재 에 배치된 스크립트 간의 차이점 추적.
- 엔진 툴이 생성하는  및  파일의 구조 변화 실시간 감시.

## 2. 동적 추적 (Dynamic Tracking)
- 엔진 툴 실행 시 생성되는 로그 파일(있는 경우)을 로 추적.
- 캐릭터의 위치 정보 및 의 변수 변화를 디버그 로그로 출력하도록 코드 보강.

## 3. 업데이트 루프
- 화면 관찰 (제오임당님 보고) -> 기획 수정 -> 코드 삽입 -> 동작 확인.
- 특히 **Option C**의 세이프 존 판정 로직이 엔진의 물리 충돌 시스템과 일치하는지 집중 추적.
