# ooo run: 실시간 실행 및 모니터링 전략

## 1. 관찰 포인트 (Monitoring)
- **위험도 동기화**: 의 1% / 10초 로직이 UI 게이지와 시각적으로 일치하는가?
- **세이프 존 판정**: 캐릭터가 중앙 구역 진입 시 게이지 정지 및 리젠 이펙트가 발생하는가?
- **보스/포탈 트리거**: 100% 도달 시 보스 스폰 및 처치 후 포탈 생성 로직의 안정성.

## 2. 작업 계획 (Execution)
- **Level 1 (Core)**: 기본 이동 및 위험도 상승 루프 완성.
- **Level 2 (Battle)**: 보스전 및 탈출 포탈 메카닉 완성.
- **Level 3 (MVP)**: 로비 정산 및 성장 데이터 연동.

## 3. 피드백 루프
- 화면 관찰 ->  가이드 업데이트 -> 코드 수정 -> 실시간 반영.
