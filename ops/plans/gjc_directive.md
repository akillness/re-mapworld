# gjc(Gajae Code) 업무 지침: 기획 통합 및 동작 테스트

## 1. 업무 목표 (Goal)
- 의 **Option C** 기획 내용을 MSW 엔진 결과물과 완벽히 합치고, 실제 동작 여부를 테스트하여 검증함.

## 2. 세부 지시 사항 (Directives)
- **코드 로드**: 의 최신 루아 스크립트를 엔진에 주입할 것.
- **UI 맵핑**: 기획 개선 사항(10% 단위 알림, 포탈 카운트다운)이 HUD 상에서 시각적으로 일치하는지 확인할 것.
- **테스트 수행**:  프로세스 상에서 '입장-전투-탈출' 세션을 실행하고, 를 생성할 것.

## 3. 결과 보고 (Reporting)
- 테스트 중 발견된 모든 Gap(기획 vs 구현 오차)은 즉시  루프에 공유하여 다음 발전 단계로 인계할 것.
